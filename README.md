# QabiilTracker

A single-page family tree app. Enter yourself, then work backward through
parents and grandparents — the whole pedigree renders at once.

## Running it

Open `index.html` directly in your browser (double-click it). There is no
server, build step, or install — it's vanilla HTML/CSS/JS, and your data is
saved locally in the browser via localStorage.
